# Future roadmap

## Pilot hardening

Move the validated browser workflows to the production architecture, add authenticated role-scoped routes, relational persistence, private media storage, migrations, background jobs, and critical-path automated tests.

## Assisted delivery

Add optional transcription, language/speech analysis, feedback drafting, facilitator calibration tools, exportable reports, richer cohort filters, and recommendation services behind feature flags.

## Enterprise extension

Add SSO, manager dashboards, LMS/HRIS integration, retention controls, multilingual scenarios, mobile/PWA support, real-time AI stakeholders, conditional branching, and advanced speech analytics without changing the core `Scenario → Run → Attempt N` model.

The extension test is architectural: more scenarios, providers, roles, and response modes add records or adapters; they do not rewrite the learning loop.
